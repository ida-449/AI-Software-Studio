# AI Software Studio

## 目标

AI Software Studio 是一个以 AI 协作为核心、以规范化流程为基础的软件产品工作室。目标是让需求、设计、开发、测试、验收与复盘全过程清晰可追踪，并持续沉淀可复用的规则、知识和模板。

## 工作方式

- 以需求和用户价值为起点，先澄清再实施。
- 使用统一流程推进产品工作，并为每个阶段保留明确产出。
- 将核心规则、角色职责、项目资料、知识、模板和报告分类管理。
- 通过自动化测试、AI 内部验收和用户体验验收共同保证质量。
- 在项目结束后复盘，将经验沉淀到工作室知识体系中。

## 产品开发生命周期

1. 需求理解
2. 需求澄清
3. PRD 输出
4. 技术架构设计
5. 风险评估
6. 开发计划
7. 编码实现
8. 自动化测试
9. AI 内部验收
10. 用户体验验收
11. 复盘沉淀
