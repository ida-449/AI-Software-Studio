# ClimbLog V0.1 测试计划

## 1. 测试目标

- 验证攀岩记录规则正确。
- 验证 IndexedDB 数据可靠且升级安全。
- 验证历史筛选和成长统计准确。
- 验证备份恢复不会破坏现有数据。
- 验证 Chrome 与 Edge 上的移动端优先体验。

## 2. 测试层级

### 单元测试

- V Scale 与法国难度表完整性、唯一性和顺序。
- 攀岩类型与难度体系匹配。
- 完成状态适用范围。
- 尝试次数校验。
- 完成率、最高难度、训练天数和趋势计算。
- 日期范围与跨日边界。
- 备份结构验证。

### 数据层测试

- IndexedDB 初始化与 schema 升级。
- 新增、查询、编辑和删除。
- 日期、类型、状态和难度筛选。
- 非法数据拒绝写入。
- 数据变更后查询与统计更新。
- 恢复失败时原数据保持不变。

### 组件与交互测试

- 切换攀岩类型后难度和状态同步变化。
- Onsight 与 Flash 自动设置尝试次数。
- 表单错误提示。
- 保存期间防重复提交。
- 删除确认。
- 筛选、空状态和数据不足提示。

### 浏览器验收

- Chrome 最新可用版本。
- Microsoft Edge 最新可用版本。
- 移动设备尺寸模拟。
- 小屏幕、横屏和较大字体。
- 刷新、关闭并重新打开页面后的数据保留。
- 离线状态下核心功能。

## 3. 功能测试场景

1. 新增抱石 Flash、Send 和 Attempt 记录。
2. 确认抱石无法选择 Onsight 或法国难度。
3. 新增难度攀登四种状态记录。
4. 确认难度攀登无法选择 V Scale。
5. 编辑记录并验证历史和统计同步更新。
6. 删除记录并验证确认步骤与统计更新。
7. 使用所有筛选条件并验证组合结果。
8. 验证两种难度体系的最高难度分别计算。
9. 验证无数据和少量数据时的提示。
10. 导出备份、清空测试数据并恢复。

## 4. 边界与异常测试

- 空可选字段。
- 超长地点、线路名称和备注。
- Send 尝试次数小于 2。
- Attempt 尝试次数小于 1。
- 非法难度值和未知完成状态。
- 同一时间快速重复保存。
- 午夜、月份切换和设备时区变化。
- 损坏 JSON、未知备份版本和缺失字段。
- IndexedDB 不可用或写入失败。
- 浏览器清除站点数据后的空状态。

## 5. 自动化命令

初始化阶段：

- `pnpm lint`
- `pnpm build`

测试框架引入后：

- `pnpm test`
- `pnpm test:coverage`

命令必须通过项目锁定的 pnpm 和 Node.js 环境执行。

## 6. 发布门禁

- P0 单元测试全部通过。
- 数据 CRUD、迁移和恢复测试通过。
- 核心流程组件测试通过。
- Chrome 与 Edge 人工验收通过。
- 无外部接口和远程数据请求。
- 备份风险提示可见。
- 没有阻塞级已知问题。

项目初始化阶段只要求：

- React + TypeScript + Vite 工程可安装依赖。
- 静态类型检查和生产构建通过。
- 基础代码检查通过。
- `docs/`、`src/`、`tests/`、`reports/` 目录存在。
- 尚未进入复杂业务功能开发。
